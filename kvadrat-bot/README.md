# Telegram-бот для студии ремонта «Квадрат» (демо для портфолио)

Бот-консультант, который превращает посетителей в заявки:

- **Калькулятор ремонта** на кнопках: площадь → тип ремонта → доп. работы → цена и срок.
  Цифры совпадают с калькулятором на лендинге (`../remont/`).
- **Запись на замер**: имя + телефон одной кнопкой «Отправить мой номер». Заявка вместе с
  расчётом сразу приходит менеджеру в Telegram и сохраняется в базу (`/leads` — последние 10).
- **ИИ-консультант**: отвечает на любые вопросы по базе знаний компании
  (`knowledge.md`), помнит контекст разговора, не выдумывает цены и ведёт к записи на замер.
  Подключается любая нейросеть с OpenAI-совместимым API (YandexGPT, DeepSeek, GPT) —
  меняется в `.env` без правки кода. Без ключа API бот работает на готовых ответах FAQ.

Стек: Python 3.11+, aiogram 3, LLM API (OpenAI-совместимый), SQLite. Покрыт тестами (`pytest`), включая
сквозной тест всего диалога.

## Запуск
1. Создай бота в @BotFather → получи токен.
2. `cp .env.example .env` и заполни `BOT_TOKEN`, `ADMIN_CHAT_ID` (и по желанию `AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL`).
3. ```
   pip install -r requirements.txt
   python bot.py
   ```
Тесты: `python -m pytest -q tests`

## Как адаптировать под другого клиента
- Тексты, цены и ответы — `knowledge.md` и `pricing.py`.
- Кнопки и сценарии — `bot.py`.
Обычно на перенастройку под новую нишу (салон, клиника, автосервис) уходит 1 день.
