# Парсер каталога интернет-магазина → Excel / Google Таблица (демо для портфолио)

Собирает **весь каталог магазина (1000 товаров за ~40 секунд)**: обходит страницы каталога,
заходит в каждую карточку и выгружает в таблицу:

- название, категорию, артикул, описание, ссылку и фото;
- цену в исходной валюте и **в рублях по курсу ЦБ РФ на сегодня**;
- остаток на складе и рейтинг.

В Excel получаются два листа:
- **«Товары»**: фильтры, закреплённая шапка, кликабельные ссылки, цветовая шкала цен;
- **«Сводка»**: по каждой категории — количество, средняя/мин/макс цена, остатки и диаграмма.

Пример результата: `books.xlsx`.

Демо работает на [books.toscrape.com](https://books.toscrape.com) — сайте, созданном
специально для тренировки парсеров.

## Техника
- Python, aiohttp: асинхронные запросы, до 8 параллельно, повтор при сбоях.
- BeautifulSoup — разбор HTML, openpyxl — Excel с форматированием и диаграммой,
  gspread — выгрузка в Google Таблицу.
- Тесты на сохранённых страницах сайта (`pytest`).

## Запуск
```
pip install -r requirements.txt
python parser.py                       # весь каталог → books.xlsx
python parser.py --limit 100           # только первые 100 товаров
python parser.py --gsheet "Каталог"    # плюс выгрузка в Google Таблицу
```
Для Google Таблицы нужен `credentials.json` сервисного аккаунта, инструкция в начале `export_gsheets.py`.

## Что можно сделать для клиента на этой основе
- мониторинг цен конкурентов по расписанию с уведомлением в Telegram об изменениях;
- выгрузку каталога поставщика для загрузки в свой интернет-магазин;
- регулярную выгрузку в Google Таблицу, которая обновляется сама.
